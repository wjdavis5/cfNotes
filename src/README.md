# cfNote - Secure Cloud Notes

A secure note-taking application with end-to-end encryption and zero-knowledge architecture.

## Security Features

cfNote is built with security and privacy as core principles:

### Key Security Features

- **End-to-end encryption**: Notes are encrypted with AES-256 in your browser
- **Zero-knowledge privacy**: User emails are only stored as secure hashes
- **Multiple security modes**:
  - **Session Storage Mode**: Encryption keys cleared when browser closes
  - **Memory-Only Mode**: Keys never persist in browser storage
- **Session timeouts**: Auto-logout after 30 minutes of inactivity
- **Page exit protection**: Automatically clears sensitive data when navigating away
- **CSRF protection**: Prevents cross-site request forgery attacks
- **Re-authentication**: Required for sensitive operations

### Implementation Details

- **Client-side encryption** using Web Crypto API
- **PBKDF2** key derivation with 100,000 iterations and SHA-256
- **Double-submit cookie pattern** for CSRF protection
- **Session management** with activity monitoring

## Getting Started

### Prerequisites

- Node.js 18+
- Angular CLI 17+

### Installation

```sh
# Clone the repository
git clone https://github.com/wjdavis5/cfNotes.git
cd cfNotes

# Install dependencies
npm install

# Start development server
nx serve web
```

### Running in development

```sh
# Start the Angular development server
nx serve web

# Start the API server
nx serve api
```

The web application will be available at http://localhost:4200

## Project Structure

This project uses Nx workspace with the following key components:

- `/web` - Angular web application with modular components
- `/api` - Cloudflare Worker API
- `/common` - Shared functionality between web and API
